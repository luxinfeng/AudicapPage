如何保存为 PNG：

  1. 在浏览器中打开此页面
  2. 右键点击上方的图片区域
  3. 选择"检查"或按 F12 打开开发者工具
  4. 在 Elements 面板中找到 class="og-image" 的 div
  5. 右键 → "Capture node screenshot"
  6. 保存为 og-share.png

或者使用截图工具截取上方 1200x630 的区域。
