Chrome 音訊即時字幕翻譯

用 Audicap 把 Chrome 分頁音訊轉成即時字幕和翻譯，適合影片、線上課程、Podcast、Webinar 和瀏覽器會議。

更新於 2026 年 5 月 16 日約 6 分鐘閱讀

快速答案

即時字幕翻譯是把正在播放的語音轉成文字，並同步翻譯成另一種語言。Audicap 直接從目前 Chrome 分頁音訊工作，因此可用於 YouTube、線上課程、Podcast、Google Meet、Zoom web 和其他一般網頁音訊。

它適合快速理解主要內容，不適合取代正式翻譯或已校對字幕。

適合的場景

  • 觀看外語 YouTube 課程或訪談。
  • 跟上使用不同語言的線上課程。
  • 理解含有專業詞彙的 Webinar 或 Podcast。
  • 參加國際 Google Meet 或 Zoom web 會議。

如何使用

  1. 在 Chrome 打開影片、課程、Podcast 或會議。
  2. 點擊 Audicap 工具列圖示。
  3. 開始目前分頁的即時轉錄。
  4. 開啟翻譯並選擇目標語言。
  5. 播放時查看逐字稿和翻譯。
  6. 結束後匯出或分享文字。

和手動翻譯比較

方式適合限制
暫停影片手動翻譯短句或單一片段。長影片會很慢，也容易中斷理解。
上傳音訊檔轉錄已經下載好的錄音。需要先下載或上傳內容。
Chrome 分頁即時翻譯邊播放邊理解影片、課程和會議。取決於音訊品質和 Chrome 擷取權限。

使用建議

盡量使用清楚音訊，不要在同一分頁同時播放多個音源。重要段落可以在結束後回頭檢查，長內容則可以搭配摘要和匯出功能整理成筆記。

常見問題

可以即時翻譯 YouTube 音訊嗎？

可以。打開 YouTube 影片後啟動 Audicap，再開啟翻譯即可。

可以用在桌面應用程式嗎？

不行。Audicap 擷取的是一般 Chrome 分頁音訊，不是桌面應用程式音訊。
